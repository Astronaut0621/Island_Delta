# 《孤岛温差》任务总清单

本文档用于统一说明项目拆分后的 6 个开发任务。每个任务都有独立任务文档，可直接分配给对应负责人。

| 任务编号 | 任务名称 | 概述 |
| --- | --- | --- |
| 任务一 | 前端地图与用户交互 | 搭建 Vue3 前端，实现地图首页、情绪点展示、热力图图层、情绪投递、地点详情、共鸣互动、智能体入口和今日温差报告页面。 |
| 任务二 | Spring Boot 业务后端 | 搭建业务后端，实现匿名用户、情绪发布、附近查询、热力图、地点详情、共鸣互动、统计报告、NLP 服务调用等核心接口。 |
| 任务三 | GaussDB 数据库与模拟数据 | 设计并创建数据库表结构，准备情绪标签字典、地点数据和 300 条以上模拟情绪数据，支撑前后端联调与演示。 |
| 任务四 | NLP 情感分析与智能体服务 | 搭建 FastAPI + PaddleNLP 服务，实现情绪分类、情感倾向、温度推荐、安全等级识别、留言生成和基础聊天能力。 |
| 任务五 | 温差地图、统计与可视化算法 | 设计情绪温度、热力图、地点温差、今日报告等统计规则，并完成前后端可视化联调和算法说明。 |
| 任务六 | 后台审核、测试、部署与答辩材料 | 实现基础后台审核、举报处理、核心测试、部署说明、项目文档、答辩 PPT 和演示流程。 |

## 推荐协作顺序

1. 任务三先完成数据库表结构和模拟数据。
2. 任务二基于数据库完成后端基础接口。
3. 任务一并行搭建前端页面，先接模拟数据，再接后端接口。
4. 任务四并行搭建 NLP 服务，后续由任务二调用。
5. 任务五在基础数据闭环完成后接入热力图和统计报告。
6. 任务六贯穿后半程，负责审核后台、测试、部署和答辩材料。

## MVP 最小交付边界

第一版必须保证以下流程完整可演示：

1. 用户匿名进入系统。
2. 地图显示校园或城市地点。
3. 用户可以选择地点并发布情绪。
4. 系统可以推荐情绪标签和温度。
5. 发布后的情绪点可以显示在地图上。
6. 用户可以查看附近留言并进行共鸣互动。
7. 地图可以展示基础热力图。
8. 系统可以生成今日温差报告。
9. 管理员可以审核和隐藏不合适内容。
10. 数据存储在 GaussDB 中，并有不少于 300 条模拟数据。
