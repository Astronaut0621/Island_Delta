## 三、安全与隐私测试用例

| 编号 | 测试项 | 测试步骤 | 预期结果 |
|------|--------|---------|---------|
| S-01 | 不保存精准原始坐标 | 检查emotion_posts表 | 只存储模糊化后的经纬度（3位小数） |
| S-02 | 不保存明文token | 检查users表 | anonymous_token_hash字段只有哈希值，无明文 |
| S-03 | 聊天不自动发布 | 用智能体聊天后检查emotion_posts | 聊天内容不会自动出现在emotion_posts中 |
| S-04 | 隐藏内容不在前台 | 将内容标记为hidden后查询前台API | 前台API不返回hidden状态的内容 |
| S-05 | 高风险内容不直接公开 | safety_level=crisis的内容 | 不直接公开展示，进入后台审核队列 |
| S-06 | 后台必须登录 | 不带token访问/api/admin/posts | 返回401未授权 |
| S-07 | 管理员密码哈希存储 | 检查admins表 | password_hash字段为BCrypt哈希，无明文密码 |
| S-08 | XSS防护 | 在内容中输入`<script>alert(1)</script>` | 内容被转义，不执行脚本 |
| S-09 | 越权删除 | 用户A尝试删除用户B的内容 | 返回403禁止 |
| S-10 | 训练样本脱敏 | 检查nlp_training_samples | 不包含姓名、学号、电话等个人信息 |
