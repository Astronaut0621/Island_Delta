# 任务一：前端地图与用户交互

## 一、任务目标

搭建《孤岛温差》的前端应用，实现用户能直接使用的主要页面和交互流程。前端需要完成地图展示、情绪点渲染、情绪投递、热力图切换、地点详情、共鸣互动、智能体入口和今日温差报告展示。

## 二、任务范围

本任务只负责前端页面、前端状态管理、前端接口调用和用户交互体验，不负责后端业务逻辑、数据库表设计和 NLP 模型实现。

技术建议：

1. Vue 3
2. Vite
3. TypeScript
4. Pinia
5. Vue Router
6. Naive UI
7. ECharts
8. 高德地图 JS API

## 三、需要完成的具体功能

### 1. 项目基础搭建

1. 创建 Vue3 + Vite + TypeScript 项目。
2. 配置 Vue Router 页面路由。
3. 配置 Pinia 状态管理。
4. 配置 API 请求封装。
5. 配置基础主题色、字体、按钮、表单和页面布局。

### 2. 匿名身份本地存储

1. 首次进入系统时调用匿名用户接口。
2. 将后端返回的 anonymous_id 和 token 保存到 localStorage。
3. 后续请求自动携带匿名身份信息。
4. 支持匿名身份过期后重新创建。

### 3. 地图首页

1. 接入高德地图 JS API。
2. 显示校园或城市地图。
3. 显示地点标记，例如图书馆、食堂、宿舍、操场、湖边、校门。
4. 显示情绪点。
5. 情绪点根据温度显示不同颜色：
   - 冷色：负向温度
   - 中性色：接近 0
   - 暖色：正向温度
6. 支持缩放、拖动和点击情绪点。

### 4. 情绪投递功能

1. 提供情绪投递入口按钮。
2. 用户可以选择或确认地点。
3. 用户可以选择情绪标签。
4. 用户可以拖动温度滑杆，范围为 -10 到 +10。
5. 用户可以填写一句话留言。
6. 用户可以选择是否允许别人共鸣。
7. 用户提交后调用发布情绪接口。
8. 发布成功后刷新地图情绪点。

### 5. NLP 推荐联动

1. 用户输入一句话后，可以点击“智能推荐”。
2. 前端调用 NLP 分析接口。
3. 自动填充推荐的情绪标签、温度和情感倾向。
4. 用户可以修改推荐结果。
5. 提交时把用户最终选择结果传给后端。

### 6. 热力图与图层切换

1. 支持普通情绪点图层。
2. 支持热力图图层。
3. 支持按情绪类型筛选，例如孤独、焦虑、压力、治愈、安心。
4. 支持按温度区间筛选，例如冷、正常、暖。
5. 调用热力图接口获取数据。

### 7. 地点详情与附近留言

1. 点击地点或情绪点后打开详情弹窗。
2. 展示地点名称、平均温度、情绪数量、主要情绪。
3. 展示附近匿名留言卡片。
4. 留言卡片展示情绪标签、温度、一句话内容、发布时间和共鸣数。

### 8. 共鸣互动

1. 每条留言支持共鸣按钮。
2. 互动类型建议包括：
   - 我也有过
   - 抱抱
   - 给你一点光
   - 谢谢你说出来
3. 点击后调用共鸣接口。
4. 成功后更新当前留言的互动数量。
5. 同一用户对同一留言的同一互动类型不能重复提交。

### 9. 智能体聊天页面

1. 提供智能体聊天入口。
2. 实现基础聊天界面。
3. 用户可以输入文字。
4. 前端调用聊天接口。
5. 展示智能体回复。
6. 智能体可以返回推荐情绪标签、温度和留言草稿。
7. 用户可以将智能体生成的留言带回投递表单。

### 10. 今日温差报告页面

1. 展示今日情绪数量。
2. 展示今日平均温度。
3. 展示最冷地点。
4. 展示最暖地点。
5. 展示主要情绪分布。
6. 使用 ECharts 展示柱状图、折线图或饼图。

## 四、接口依赖

前端至少需要对接以下接口：

```text
POST /api/users/anonymous
POST /api/emotions
GET  /api/emotions/nearby
GET  /api/map/heatmap
GET  /api/locations/{id}
POST /api/reactions
POST /api/nlp/analyze
POST /api/chat/message
GET  /api/statistics/today
```

## 五、交付物

1. 可运行的前端项目。
2. 完整页面路由。
3. 地图首页。
4. 情绪投递页面或弹窗。
5. 地点详情弹窗。
6. 智能体聊天页面。
7. 今日温差报告页面。
8. 与后端接口联调完成的前端代码。

## 六、验收标准

1. 地图可以正常加载和交互。
2. 情绪点可以正常展示。
3. 用户可以完成一次完整情绪投递。
4. 投递成功后地图能刷新出新数据。
5. 可以查看附近留言。
6. 可以点击共鸣按钮并更新数量。
7. 可以使用 NLP 推荐情绪标签和温度。
8. 今日温差报告页面能显示真实接口数据。
9. 页面在常见电脑浏览器中无明显错位。
