# 任务六：后台审核、测试、部署与答辩材料

## 一、任务目标

完成《孤岛温差》的基础后台管理、内容审核、举报处理、测试验证、部署说明和答辩材料。该任务保证项目最终可以稳定演示，并且能说明隐私保护、内容安全、技术架构和项目价值。

## 二、任务范围

本任务负责后台管理页面、审核流程、测试文档、部署说明、项目说明书、答辩 PPT 和演示脚本。不负责核心前端地图开发、不负责主要业务接口、不负责 NLP 模型实现。

## 三、需要完成的具体功能

### 1. 管理员登录

1. 实现基础管理员登录页面。
2. 支持用户名和密码登录。
3. 密码必须使用 hash 存储。
4. 登录后进入后台首页。
5. 未登录不能访问后台页面。

页面：

```text
/admin/login
```

### 2. 情绪内容审核

管理员可以查看用户发布的情绪内容。

功能：

1. 查看情绪列表。
2. 按状态筛选：normal、pending、hidden、deleted。
3. 按情绪类型筛选。
4. 按时间筛选。
5. 查看内容详情。
6. 隐藏不合适内容。
7. 恢复被隐藏内容。
8. 删除违规内容。

页面：

```text
/admin/posts
```

### 3. 举报处理

管理员可以处理用户举报。

功能：

1. 查看举报列表。
2. 查看举报原因。
3. 查看被举报内容。
4. 标记为已处理。
5. 标记为忽略。
6. 处理后同步更新内容状态。

页面：

```text
/admin/reports
```

### 4. 统计后台

展示项目运营和演示所需的基础数据。

功能：

1. 总情绪数量。
2. 今日情绪数量。
3. 平均温度。
4. 最冷地点。
5. 最暖地点。
6. 高频情绪标签。
7. 最近发布趋势。

页面：

```text
/admin/statistics
```

### 5. NLP 反馈查看

查看用户是否采纳或修正模型推荐结果。

功能：

1. 查看模型预测记录。
2. 查看用户修正后的情绪标签。
3. 查看用户修正后的温度。
4. 统计模型推荐采纳率。

页面：

```text
/admin/nlp-feedback
```

### 6. 功能测试

需要覆盖以下核心流程：

1. 匿名进入。
2. 地图加载。
3. 情绪投递。
4. NLP 推荐。
5. 地图情绪点刷新。
6. 附近留言查询。
7. 共鸣互动。
8. 热力图展示。
9. 今日温差报告。
10. 后台审核。

### 7. 接口测试

至少测试以下接口：

```text
POST /api/users/anonymous
POST /api/emotions
GET  /api/emotions/nearby
GET  /api/map/heatmap
GET  /api/locations/{id}
POST /api/reactions
POST /api/nlp/analyze
POST /api/chat/message
GET  /api/statistics/today
```

测试内容：

1. 正常参数。
2. 缺少参数。
3. 非法温度。
4. 非法用户。
5. 重复共鸣。
6. 空内容。
7. 超长内容。

### 8. 安全与隐私测试

需要验证：

1. 不保存用户精准原始坐标。
2. 不保存明文匿名 token。
3. 用户聊天内容不会自动发布到地图。
4. 被隐藏内容不会出现在前台。
5. 高风险内容不能直接公开发布。
6. 管理后台必须登录后访问。

### 9. 部署说明

需要写清楚：

1. 前端如何启动。
2. Spring Boot 后端如何启动。
3. FastAPI NLP 服务如何启动。
4. GaussDB 如何初始化。
5. 环境变量如何配置。
6. 演示数据如何导入。

建议包含：

```text
npm install
npm run dev

mvn spring-boot:run

uvicorn main:app --host 0.0.0.0 --port 8000

psql / gsql 执行 schema.sql 和 seed.sql
```

### 10. 答辩材料

需要准备：

1. 项目说明书。
2. 答辩 PPT。
3. 演示脚本。
4. 技术架构图。
5. 数据库 ER 图。
6. 主要接口说明。
7. NLP 模型说明。
8. 隐私与内容安全说明。
9. 测试结果说明。
10. 项目风险与解决方案。

### 11. 推荐演示流程

答辩演示建议按以下顺序：

1. 介绍项目定位：匿名情绪地图。
2. 展示地图首页。
3. 展示已有情绪点和热力图。
4. 匿名发布一条情绪。
5. 使用智能体推荐情绪标签和温度。
6. 发布后在地图上查看新情绪点。
7. 点击附近留言并进行共鸣。
8. 查看今日温差报告。
9. 展示后台审核。
10. 展示数据库和 NLP 预测记录。

## 五、验收标准

1. 管理员可以登录后台。
2. 管理员可以隐藏、恢复和删除情绪内容。
3. 管理员可以处理举报。
4. 被隐藏内容不会显示在前台。
5. 核心功能测试通过。
6. 核心接口测试通过。
7. 部署说明可以让其他同学独立启动项目。
8. 答辩材料完整，能够说明项目背景、架构、功能、数据库、NLP、隐私安全和测试结果。
