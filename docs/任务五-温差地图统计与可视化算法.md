# 任务五：温差地图、统计与可视化算法

## 一、任务目标

设计《孤岛温差》的核心数据计算逻辑，包括情绪温度、热力图权重、地点平均温度、今日温差报告、主要情绪分布、最冷地点和最暖地点等。该任务需要让地图和报告页不仅能显示数据，而且能体现“温差”的产品概念。

## 二、任务范围

本任务负责算法规则、统计口径、热力图数据结构、报告数据结构和可视化联调。不负责数据库建表、不负责完整前端页面、不负责基础后端 CRUD。

## 三、需要完成的具体功能

### 1. 温度区间规则

将 -10 到 +10 的温度划分为区间。

建议：

```text
-10 到 -7：very_cold
-6 到 -2：cold
-1 到 +1：neutral
+2 到 +6：warm
+7 到 +10：hot
```

需要输出：

1. temperature_bin 计算规则。
2. 每个区间对应颜色。
3. 每个区间对应前端展示文案。

### 2. 地点平均温度

计算每个地点的平均温度。

MVP 算法：

```text
地点平均温度 = 该地点公开且正常状态情绪记录的 temperature 平均值
```

可选优化：

```text
地点平均温度 = 最近 N 天情绪记录的时间衰减加权平均值
```

### 3. 时间衰减规则

用于让近期情绪在热力图和统计中权重更高。

建议：

```text
24 小时内：1.0
1 到 3 天：0.7
3 到 7 天：0.4
7 天以上：0.2
```

输出：

1. 时间衰减函数说明。
2. 后端实现伪代码或代码。
3. 答辩可解释版本。

### 4. 热力图权重算法

热力图需要返回经纬度和权重。

MVP 算法：

```text
heat_weight = abs(temperature) * time_decay
```

如果同一区域有多条记录：

```text
grid_heat_weight = sum(abs(temperature) * time_decay)
```

返回格式建议：

```json
[
  {
    "latitude": 30.123456,
    "longitude": 120.123456,
    "weight": 8.4,
    "avg_temperature": -5.6,
    "post_count": 12,
    "main_emotion": "stressed"
  }
]
```

### 5. 主要情绪计算

统计某个区域或地点出现次数最多的 emotion_type。

规则：

```text
main_emotion = count(emotion_type) 最大的情绪标签
```

如果数量相同：

1. 优先选择最近 24 小时更多的标签。
2. 仍然相同则返回任意一个，并附带并列说明。

### 6. 今日温差报告

报告需要包含：

1. 今日情绪总数。
2. 今日平均温度。
3. 今日最冷地点。
4. 今日最暖地点。
5. 今日主要情绪。
6. 情绪类型分布。
7. 温度区间分布。
8. 分时段情绪数量。

接口返回建议：

```json
{
  "date": "2026-06-10",
  "post_count": 320,
  "avg_temperature": -1.8,
  "coldest_location": "图书馆",
  "warmest_location": "湖边草坪",
  "main_emotion": "stressed",
  "emotion_distribution": [],
  "temperature_distribution": [],
  "hourly_distribution": []
}
```

### 7. 地点情绪档案

如果时间允许，为地点详情提供以下统计：

1. 地点平均温度。
2. 地点情绪数量。
3. 地点主要情绪。
4. 地点最近留言。
5. 地点温度趋势。
6. 地点情绪分布。

### 8. 前端可视化联调

需要与任务一配合完成：

1. 地图热力图显示。
2. 情绪点颜色显示。
3. 今日报告 ECharts 图表。
4. 地点详情统计展示。

建议图表：

1. 情绪分布饼图。
2. 温度区间柱状图。
3. 分时段折线图。
4. 地点温度排行。

4. 地点统计口径。
5. 后端计算逻辑或伪代码。
6. 前端可视化联调结果。
7. 答辩用算法说明。

## 六、验收标准

1. 热力图可以根据情绪数据生成冷暖区域。
2. 今日报告数据与数据库记录基本一致。
3. 最冷地点和最暖地点计算逻辑清晰。
4. 主要情绪统计结果正确。
5. 图表能正常展示接口返回的数据。
6. 算法简单、稳定、可解释，适合课程项目答辩。
